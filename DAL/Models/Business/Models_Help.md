# Описание моделей (Business)

В данном разделе представлены модели бизнес-логики (DAL.Models.Business), используемые в системе.

| Название модели | Описание |
| :--- | :--- |
| **Article** | Статья (пост) в блоге или новостях. Содержит общую информацию: слаг, категорию, автора и флаги публикации. |
| **ArticleComment** | Комментарий пользователя к статье. Поддерживает древовидную структуру (ответы на комментарии). |
| **ArticleSoftware** | Связующая таблица для привязки программного обеспечения (Software) к статьям. |
| **ArticleTag** | Связующая таблица для привязки тегов (TagBusiness) к статьям. |
| **ArticleTranslation** | Перевод контента статьи (заголовок, текст, краткое описание) на разные языки. |
| **Category** | Категория (для софта или статей). Поддерживает иерархическую структуру (родительские и дочерние категории). |
| **CategoryTranslation** | Перевод названия и описания категории на разные языки. |
| **Developer** | Информация о разработчике ПО (название, сайт, логотип, описание). |
| **LicenseType** | Тип лицензии программного обеспечения (например, Free, Shareware, Open Source). |
| **Platform** | Платформа или операционная система (Windows, macOS и т.д.). Теперь содержит только технические данные (Code, Family). |
| **PlatformTranslation** | Локализованные данные платформы: название на конкретном языке, описание и SEO-параметры. |
| **Review** | Отзыв и оценка пользователя для конкретного программного обеспечения. |
| **SeoEntity** | Сущность для управления SEO-параметрами (Index, Follow) для различных объектов системы. |
| **SeoTranslation** | Локализованные SEO-данные: MetaTitle, MetaDescription, Keywords, Canonical URL и Slug. |
| **Software** | Основная сущность программного обеспечения. Связывает разработчика, лицензию и все сопутствующие данные. |
| **SoftwareAlias** | Альтернативные названия программы (алиасы), используемые для улучшения поиска. |
| **SoftwareAlternative** | Описание взаимосвязей между программами (аналоги, альтернативы). |
| **SoftwareAsset** | Медиа-файлы программного обеспечения (иконки, скриншоты, промо-изображения). |
| **SoftwareCategory** | Связь программного обеспечения с категориями (поддерживает несколько категорий для одного ПО). |
| **SoftwareLink** | Полезные ссылки для ПО (официальный сайт, GitHub, документация и т.д.). |
| **SoftwareNews** | Новости и анонсы, относящиеся к конкретному программному обеспечению. |
| **SoftwareStatistics** | Агрегированная статистика: количество просмотров, скачиваний, средний рейтинг и количество отзывов. |
| **SoftwareTag** | Теги, привязанные к программному обеспечению для классификации и поиска. |
| **SoftwareTranslation** | Локализованное название, краткое и полное описание программного обеспечения. |
| **SoftwareVersion** | Конкретная версия программного обеспечения (номер версии, дата релиза, статус стабильности). |
| **SoftwareVersionPlatform** | Связь конкретной версии ПО с платформой (ОС) и архитектурой. |
| **SoftwareVersionPlatformFile** | Информация о файлах для скачивания (URL, тип файла, размер, контрольная сумма SHA256). |
| **TagBusiness** | Бизнес-теги, используемые для классификации как статей, так и программного обеспечения. |
| **TagTranslation** | Локализованное название и описание тега. |
| **UpdateFeed** | Лента обновлений (Changelog) для конкретной версии ПО, содержащая описание изменений. |
