# Обзор структуры моделей (Summary)

Ниже представлен перечень всех сущностей агрегатора и их назначение в системе.

| **Сущность**       | **Описание**                                                                                                          | **Ключевые связи**                |
| :------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------- |
| **AggregatorSource**       | Магазины или сайты-источники данных (Play Store, сайт автора).                             | Ссылка в `MarketData`                       |
| **CategoryOfAggregator**   | Иерархический справочник категорий (Категория -> Подкатегория).                | `Parent`, `Programs`                             |
| **DeveloperOfAggregator**  | Информация об авторе или компании-разработчике ПО.                                       | `Programs`                                         |
| **DownloadLink**           | Прямые ссылки на файлы, привязанные к архитектуре и версии.                        | `Version`                                          |
| **DownloadLog**            | Журнал событий скачивания для аналитики и трекинга.                                     | `Version`, `DownloadLink`                      |

| **LanguageOfAggregator**   | Справочник языков системы, на которые переводятся данные.                          | Все сущности `Localization`             |
| **LicenseType**            | Типы лицензий (Freeware, Shareware, Subscription).                                                                      | `ProgramLocalization`                              |
| **MarketData**             | Динамические данные парсинга: рейтинги, цены, кол-во скачиваний в сторе. | `Program`, `Source`, `Language`                |
| **PlatformOfAggregator**   | Список поддерживаемых ОС (Windows, Android, iOS и т.д.).                                                   | `ProgramPlatform` (Many-to-Many)                   |
| **ProgramLocalization**    | Текстовый контент (описания, анонсы, мета-теги) на разных языках.               | `Program`, `Language`, `LicenseType`           |
| **ProgramOfAggregator**    | **Центральная сущность:** Карточка программы. Хранит общие данные.       | `Category`, `Developer`, `Versions`, `Media` |
| **ProgramPlatform**        | Связывает программу с ОС и указывает минимальные системные требования. | `Program`, `Platform`                            |
| **ProgramTagOfAggregator** | Связь программы с тегами (Many-to-Many).                               | `Program`, `Tag`                                 |
| **ScreenshotOfAggregator** | Изображения интерфейса (галерея).                                                                       | `Program`, `Localizations` (Alt-текст)      |
| **VersionLocalization**    | Описание изменений (What's new) for конкретной версии.                                             | `Version`, `Language`                            |
| **VersionOfAggregator**    | Конкретный релиз программы с номером версии и статусом (Beta/Stable).                | `Program`, `DownloadLinks`, `Localizations`    |
| **TagOfAggregator**        | Справочник тегов для классификации программ.                               | `ProgramTags`, `Localizations`               |
| **VideoOfAggregator**      | Ссылки на видео-превью или обзоры (YouTube/MP4).                                                        | `Program`, `Localizations`                       |

# 1. Базовая иерархия (Core)

```csharp
/// <summary>
/// Единый корень для всех сущностей.
/// </summary>
public abstract class BaseEntityOfAggregator
{
    [Key]
    public int Id { get; protected set; }

    protected BaseEntityOfAggregator() { }
}

/// <summary>
/// Интерфейс мягкого удаления.
/// </summary>
public interface ISoftDeletableOfAggregator
{
    bool IsDeleted { get; }
    DateTimeOffset? DeletedAt { get; }

    void Delete();
    void Restore();
}

/// <summary>
/// Интерфейс аудита.
/// </summary>
public interface IAuditableOfAggregator
{
    DateTimeOffset CreatedAt { get; }
    DateTimeOffset? UpdatedAt { get; }
}

/// <summary>
/// Базовая модель с аудитом.
/// </summary>
public abstract class AuditableEntityOfAggregator : BaseEntityOfAggregator, IAuditableOfAggregator
{
    public DateTimeOffset CreatedAt { get; protected set; }
    public DateTimeOffset? UpdatedAt { get; protected set; }

    protected AuditableEntityOfAggregator() { }

    /// <summary>Вызывается при создании сущности</summary>
    protected internal void SetCreated()
    {
        CreatedAt = DateTimeOffset.UtcNow;
    }

    /// <summary>Вызывается при обновлении</summary>
    protected internal void SetUpdated()
    {
        UpdatedAt = DateTimeOffset.UtcNow;
    }
}

/// <summary>
/// Полная модель с аудитом и мягким удалением.
/// </summary>
public abstract class FullAuditableEntityOfAggregator : AuditableEntityOfAggregator, ISoftDeletableOfAggregator
{
    public bool IsDeleted { get; protected set; }
    public DateTimeOffset? DeletedAt { get; protected set; }

    protected FullAuditableEntityOfAggregator() { }

    public virtual void Delete()
    {
        if (IsDeleted) return;

        IsDeleted = true;
        DeletedAt = DateTimeOffset.UtcNow;

        SetUpdated();
    }

    public virtual void Restore()
    {
        IsDeleted = false;
        DeletedAt = null;
    }
}

```

**Важно:** Все таблицы локализаций наследуют `AuditableEntityOfAggregator` (без soft-delete), так как мягкое удаление отдельного перевода не имеет смысла и добавляет лишние колонки.

# 2. AggregatorSource

Сущность предназначена для регистрации и управления внешними источниками данных (площадками), с которых агрегатор собирает информацию (Google Play, сайт автора и т.д.). Служит для классификации данных парсинга и формирования внешних ссылок.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| **Name** | `string(100)` | Название источника. Обязательное поле. |
| **Slug** | `string(100)` | Уникальный ID для URL. Индексирован. |
| **BaseUrl** | `string(2048)` | Базовый URL площадки. |
| **IsActive** | `bool` | Флаг активности. |
| **SortOrder**| `int` | Порядок сортировки. |

**Технические особенности:**
*   **Наследование:** `FullAuditableEntityOfAggregator` (Аудит + Soft Delete).
*   **Уникальность:** Индекс `UX_AggregatorSource_Slug`.

```csharp
[Table("aggregator_sources")]
public class AggregatorSource : FullAuditableEntityOfAggregator
{
    [Required, MaxLength(100)]
    public string Name { get; set; } = string.Empty;

    [Required, MaxLength(100)]
    public string Slug { get; set; } = string.Empty;

    [MaxLength(2048)]
    public string? BaseUrl { get; set; }

    public bool IsActive { get; set; } = true;
    public int SortOrder { get; set; } = 0;
}
```
