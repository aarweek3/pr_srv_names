# 1. Базовые сущности и Интерфейсы

Все модели агрегатора наследуются от базовых классов, обеспечивающих аудит и мягкое удаление.

```csharp
public abstract class BaseEntityOfAggregator
{
    [Key]
    public int Id { get; protected set; }
}

public abstract class AuditableEntityOfAggregator : BaseEntityOfAggregator, IAuditableOfAggregator
{
    public DateTimeOffset CreatedAt { get; protected set; }
    public DateTimeOffset? UpdatedAt { get; protected set; }
}

public abstract class FullAuditableEntityOfAggregator : AuditableEntityOfAggregator, ISoftDeletableOfAggregator
{
    public bool IsDeleted { get; protected set; }
    public DateTimeOffset? DeletedAt { get; protected set; }
}
```

# 4. Локализации (Localization Models)

Все локализации имеют обязательную связь с сущностью и языком, а также уникальный индекс по этой паре.

| Модель | FK к сущности | FK к языку | Уникальность |
| :--- | :--- | :--- | :--- |
| **Program...Localization** | `int` (Required) | `int` (Required) | (ProgramId, LanguageId) |
| **Category...Localization** | `int` (Required) | `int` (Required) | (CategoryId, LanguageId) |
| **Platform...Localization** | `int` (Required) | `int` (Required) | (PlatformId, LanguageId) |

Пример реализации:
```csharp
[Table("category_of_aggregator_localizations")]
[Index(nameof(CategoryOfAggregatorId), nameof(LanguageOfAggregatorId), IsUnique = true)]
public class CategoryOfAggregatorLocalization : AuditableEntityOfAggregator
{
    public int CategoryOfAggregatorId { get; set; }
    public virtual CategoryOfAggregator CategoryOfAggregator { get; set; } = null!;

    public int LanguageOfAggregatorId { get; set; }
    public virtual LanguageOfAggregator LanguageOfAggregator { get; set; } = null!;

    [Required, MaxLength(255)]
    public string Name { get; set; } = string.Empty;
}
```

// Индексы логов
